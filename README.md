# insta-kit

Набор скиллов для Claude Code на русском языке для ведения Instagram (СНГ, Кыргызстан): поиск залетевших рилсов, разбор своих постов, оценка профиля, сценарии рилсов с оценкой хуков, подписи и чистка ИИ-штампов.

**Принцип: ничего не публикуется и не отправляется без вашего явного «да».** Скиллы исследуют, пишут и проверяют; публикация всегда отдельным шагом по вашей команде.

## Установка

Через маркетплейс плагинов:

```
/plugin marketplace add <owner>/insta-kit
/plugin install insta-kit@insta-kit
```

Или вручную, как обычные скиллы:

```
git clone https://github.com/<owner>/insta-kit
cp -r insta-kit/skills/* ~/.claude/skills/
```

(при ручной установке скрипты вызываются из `~/.claude/skills/<скилл>/`; в каждом SKILL.md указан запасной путь.)

## Настройка

Личные данные хранятся вне репозитория, в `~/.claude/insta-kit/`:

1. `accounts.json`: массив аккаунтов (`key`, `username`, `niche`, `composio_account` по желанию, `competitors`). Пример: `templates/accounts.example.json`.
2. `voice-<key>.md`: голос аккаунта (ниша, аудитория, тон, запретные слова, что заходит, кодовое слово). Шаблон: `templates/voice.md`.

Если файлов нет, скилл спросит нужное и предложит их создать.

## Команды (скиллы)

| Скилл | Что делает | Говорите |
|---|---|---|
| `ig-viral` | Собирает рилсы конкурентов, считает кратность просмотров к медиане аккаунта (>= 3x сигнал, < 1.5x шум), разбирает хуки лидеров, пишет свайп-файл | «найди залетевшие рилсы» |
| `ig-audit` | Ранжирует ваши посты по охвату, сохранениям и пересылкам на 1000 охвата, досмотру; что повторить и бросить, 3 гипотезы | «разбери мои посты» |
| `ig-profile` | Оценка профиля по рубрике из 100 баллов (12 пунктов) и переписанные варианты | «оцени профиль» |
| `ig-reel` | Идея, 3 хука из 26 формул с оценкой, сценарий, экранный текст, тайминг и проверка петли | «напиши сценарий рилса» |
| `ig-caption` | Подпись: превью первых 125 символов, один призыв, кодовое слово, 3-5 хештегов, без ссылок | «напиши подпись» |
| `ig-human` | Чистка русских ИИ-штампов, длинных тире и невидимых символов | «убери ИИ-штампы» |

Скрипты (Python 3.10+, только стандартная библиотека): `outliers.py`, `audit.py`, `hookscore.py`, `beats.py`, `caption.py`, `clean.py`. Тесты: `python tests/run_tests.py`.

## Источники данных (всё необязательно)

- **Apify MCP**: чужие аккаунты и конкуренты (`mcp__apify__apify--instagram-reel-scraper`, `mcp__apify__get-dataset-items`). Запуски тратят кредиты Apify; транскрипты (`includeTranscript`) платные за минуту аудио, поэтому запрашиваются только для отобранных лидеров.
- **Composio CLI**: свои аккаунты (`INSTAGRAM_GET_IG_USER_MEDIA`, `INSTAGRAM_GET_IG_MEDIA_INSIGHTS`, `INSTAGRAM_GET_USER_INFO`). На Windows Composio может стоять в WSL: `wsl -d Ubuntu -- bash -lc "composio ..."`.
- **Без MCP**: вставьте таблицу, CSV или ссылки вручную; скрипты принимают JSON, CSV и TSV.
