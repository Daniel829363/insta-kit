# insta-kit

Набор скиллов для Claude Code на русском языке для ведения Instagram (СНГ, Кыргызстан): поиск залетевших рилсов, разбор своих постов, оценка профиля, сценарии рилсов с оценкой хуков, подписи и чистка ИИ-штампов, а также монтаж видео, шортсы, ролики без съёмки и публикация.

**Принцип: ничего не публикуется и не отправляется без вашего явного «да».** Скиллы исследуют, пишут, монтируют и проверяют; публикация (`ig-publish`) всегда отдельным шагом по вашей команде, после превью.

## Установка

Через маркетплейс плагинов:

```
/plugin marketplace add <owner>/insta-kit
/plugin install insta-kit@insta-kit
```

Или вручную, как обычные скиллы:

```
git clone https://github.com/<owner>/insta-kit
cp -r insta-kit/skills/* ~/.claude/skills/
```

(при ручной установке скрипты вызываются из `~/.claude/skills/<скилл>/`; в каждом SKILL.md указан запасной путь.)

## Настройка

Личные данные хранятся вне репозитория, в `~/.claude/insta-kit/`:

1. `accounts.json`: массив аккаунтов (`key`, `username`, `niche`, `composio_account` по желанию, `competitors`). Пример: `templates/accounts.example.json`.
2. `voice-<key>.md`: голос аккаунта (ниша, аудитория, тон, запретные слова, что заходит, кодовое слово). Шаблон: `templates/voice.md`.

Если файлов нет, скилл спросит нужное и предложит их создать.

## Команды (скиллы)

| Скилл | Что делает | Говорите |
|---|---|---|
| `ig-viral` | Собирает рилсы конкурентов, считает кратность просмотров к медиане аккаунта (>= 3x сигнал, < 1.5x шум), разбирает хуки лидеров, пишет свайп-файл | «найди залетевшие рилсы» |
| `ig-audit` | Ранжирует ваши посты по охвату, сохранениям и пересылкам на 1000 охвата, досмотру; что повторить и бросить, 3 гипотезы | «разбери мои посты» |
| `ig-profile` | Оценка профиля по рубрике из 100 баллов (12 пунктов) и переписанные варианты | «оцени профиль» |
| `ig-reel` | Идея, 3 хука из 26 формул с оценкой, сценарий, экранный текст, тайминг и проверка петли | «напиши сценарий рилса» |
| `ig-caption` | Подпись: превью первых 125 символов, один призыв, кодовое слово, 3-5 хештегов, без ссылок | «напиши подпись» |
| `ig-human` | Чистка русских ИИ-штампов, длинных тире и невидимых символов | «убери ИИ-штампы» |

Скрипты (Python 3.10+, только стандартная библиотека): `outliers.py`, `audit.py`, `hookscore.py`, `beats.py`, `caption.py`, `clean.py`, `tts_elevenlabs.py`. Тесты: `python tests/run_tests.py`.

## Видео: то, чего нет у других наборов

| Скилл | Что делает | Говорите |
|---|---|---|
| `ig-cut` | Монтирует ваше видео под Reels на FFmpeg: вырезает паузы и «э-э», 9:16 с размытым фоном, субтитры с подсветкой слов, громкость -14 LUFS, проверка `check reels` | «смонтируй рилс», «вырежи паузы» |
| `ig-shorts` | Нарезает длинное видео (подкаст, вебинар) на вертикальные шортсы через claude-shorts, выбирает куски под голос аккаунта и проверяет результат | «нарежь шортсы» |
| `ig-video` | Ролик без съёмки: сценарий, озвучка ElevenLabs одним запросом с таймингами слов (`tts_elevenlabs.py`), моушн-графика в Remotion, превью | «сделай ролик без съёмки» |
| `ig-publish` | Публикует рилс, пост, карусель или сторис через Composio, только после «да» на превью (файл + подпись + аккаунт) | «опубликуй рилс» |

Зависимости (всё необязательно; каждый скилл сам говорит, чего не хватает):
- **FFmpeg 6.1+** в PATH (`ffmpeg -version`): монтаж, звук, проверки.
- **ffmpeg-skill** ([kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill), MIT): `npx ffmpeg-skill`. Нужен для `ig-cut` и проверок в остальных. Для субтитров и вырезания «э-э»: `pip install faster-whisper "av<16"`.
- **claude-shorts** ([AgriciDaniel/claude-shorts](https://github.com/AgriciDaniel/claude-shorts), MIT): `git clone ... ~/.claude/skills/shorts`, для `ig-shorts` (на Windows см. заметки в скилле).
- **Node.js и Remotion** ([remotion.dev](https://www.remotion.dev)): рендер графики для `ig-video`. Проверьте условия лицензии Remotion для коммерческого использования.
- **Ключ ElevenLabs** в переменной `ELEVENLABS_API_KEY`: озвучка в `ig-video`. Платит ваш аккаунт; `--dry-run` показывает запрос и число символов (кредитов) без вызова. На бесплатном тарифе ElevenLabs запрещено коммерческое использование.
- **Composio CLI**: публикация в `ig-publish`.

## Источники данных (всё необязательно)

- **Apify MCP**: чужие аккаунты и конкуренты (`mcp__apify__apify--instagram-reel-scraper`, `mcp__apify__get-dataset-items`). Запуски тратят кредиты Apify; транскрипты (`includeTranscript`) платные за минуту аудио, поэтому запрашиваются только для отобранных лидеров.
- **Composio CLI**: свои аккаунты (`INSTAGRAM_GET_IG_USER_MEDIA`, `INSTAGRAM_GET_IG_MEDIA_INSIGHTS`, `INSTAGRAM_GET_USER_INFO`). На Windows Composio может стоять в WSL: `wsl -d Ubuntu -- bash -lc "composio ..."`.
- **Без MCP**: вставьте таблицу, CSV или ссылки вручную; скрипты принимают JSON, CSV и TSV.
