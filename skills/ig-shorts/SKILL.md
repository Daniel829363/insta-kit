# ig-shorts: шортсы из длинного видео

Отвечай по-русски. Ничего не публикуй и не отправляй без явного «да» пользователя.

Скилл-маршрутизатор над внешним **claude-shorts** (AgriciDaniel/claude-shorts, MIT, команда `/shorts`): он расшифровывает видео, Claude выбирает сильные куски, Remotion рисует анимированные субтитры, FFmpeg экспортирует. Наша часть: когда брать, как поставить, как выбрать куски под голос аккаунта и как проверить результат.

## Когда использовать
- Есть длинное видео (от 5 минут) с речью: подкаст, интервью, вебинар, урок, стрим, длинный ролик на YouTube.
- Нужно 3-10 вертикальных клипов по 20-60 секунд.
- **Не подходит** (или подходит хуже): запись экрана, скринкасты, видео без речи, музыкальные клипы. claude-shorts рассчитан на говорящую голову: слежение за лицом и кадрирование под него. Для записи экрана он кладёт кадр в letterbox (полосы сверху и снизу), это нормально для чернового, но для красивого результата используй `ig-cut` (blur-фон) на вырезанном куске или `ig-video`.
- Короткое видео, которое надо просто подчистить: тебе нужен `ig-cut`, а не этот скилл.

## 0. Установка (один раз)
Проверь `~/.claude/skills/shorts/SKILL.md`. Если нет:
```
git clone https://github.com/AgriciDaniel/claude-shorts ~/.claude/skills/shorts
```
Дальше зависимости: прочитай README репозитория (там установщик `install.sh` для Linux/macOS) и поставь их по списку ниже; проверка входного файла и окружения: `scripts/preflight.sh`. Нужны: FFmpeg + ffprobe, Python 3.10+, Node.js (для Remotion), `jq`, faster-whisper; для скорости видеокарта NVIDIA (CUDA).

### Заметки по Windows (Git Bash)
Оригинал писали под Linux/macOS, на Windows нужны поправки:
- Запускать скрипты в Git Bash (`bash scripts/...`), не в PowerShell. Временную папку брать как `SHORTS_TMP="$(cygpath -m /tmp)/claude-shorts"` (путь, понятный и bash, и Windows-Python).
- Виртуальное окружение Windows: активация `Scripts/activate`, а не `bin/activate`.
- `bc` в Git Bash нет: арифметику в скриптах заменить на `awk`.
- `ffprobe` из FFmpeg 9 в режиме csv отдаёт CRLF и хвостовые запятые: чистить `| tr -d '\r' | sed 's/,*$//'`, иначе числа не парсятся.
- Версии, которые работают вместе: `mediapipe==0.10.21`, `opencv-contrib-python==4.11.*`, `numpy<2`, `av<16` (с av 16+ ломается faster-whisper, ошибка `metadata_errors`).
- GPU: поставить CUDA-сборку torch (`pip install torch --index-url https://download.pytorch.org/whl/cu128`, индекс подбери под свою видеокарту; для RTX 50xx нужен cu128 и новее). Без GPU работает на CPU, но расшифровка в разы медленнее.
- `jq`: `winget install jqlang.jq`, потом открыть новое окно терминала (PATH).
Если что-то из этого уже поправлено в установленной копии, не переделывай; проверь запуском `bash ~/.claude/skills/shorts/scripts/preflight.sh <видео>`.

## 1. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` и `voice-<key>.md`: ниша, аудитория, тон, табу, кодовое слово. Спроси: файл, аккаунт, сколько клипов, длительность (по умолчанию 20-60 с), язык (ru), стиль субтитров (Bold, Bounce, Clean).

## 2. Выбор лучших кусков (твоя часть)
claude-shorts покажет кандидатов с оценкой. Дополни выбор критериями аккаунта:
- Хук в первые 3 секунды: цифра, ставка, спорная мысль, обещание. Прогони первые фразы через `ig-reel` (`hookscore.py`): кандидат с хуком < 50 баллов предложи начать на пару секунд позже или с другой фразы.
- Кусок самодостаточный: понятен без контекста всего видео, есть начало мысли и конец.
- Совпадает с темами и тоном из `voice-<key>.md`, нет слов-табу.
- Нет чувствительного: чужие персональные данные, цены и обещания, которые пользователь не одобрял.
Покажи таблицу: таймкод, длительность, хук, балл, почему. Пользователь выбирает и правит границы, ты не рендеришь без выбора.

## 3. Рендер
Запускай `/shorts` по его шагам (preflight, транскрипция, анализ, согласование, привязка границ к паузам, рендер, экспорт). Результат: `short_01_ig.mp4` и т.п. в выбранной папке. Все клипы собирай в отдельную новую папку.

## 4. Проверка через ig-cut
Каждый клип прогони (путь к ffmpeg-skill см. `ig-cut`):
```
python3 ~/.claude/skills/ffmpeg-skill/scripts/check.py short_01_ig.mp4 --platform reels --content
```
Исправь FAIL командой из колонки `fix` (чаще всего громкость: `loudness.py -I -14`). Если ffmpeg-skill не стоит, поставь по инструкции `ig-cut` (`npx ffmpeg-skill`).

## 5. Выдача
Покажи список клипов: файл, длительность, хук, итог `check`. Подписи через `ig-caption` и `ig-human`, публикация через `ig-publish` только после явного «да» на превью каждого клипа.
