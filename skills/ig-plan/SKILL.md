# ig-plan: план на неделю из данных, а не из головы

Отвечай по-русски. Ничего не публикуй, не отправляй и не ставь в расписание без явного «да» пользователя. Скилл только планирует и пишет файл в `~/.claude/insta-kit/`.

## 0. Что прочитать
1. `~/.claude/insta-kit/accounts.json`. Если аккаунтов несколько, спроси, для какого план (или для всех по очереди). Из записи нужны `key`, `username`, `niche`, `competitors`. Нет файла: спроси ник, нишу, конкурентов и предложи его создать (`templates/accounts.example.json`).
2. `~/.claude/insta-kit/voice-<key>.md`: тон, табу, кодовое слово, куда ведём (воронка). Кодовое слово берётся отсюда или из поля аккаунта; если его нет, спроси, нужно ли (одно слово на неделю, не по слову на пост).
3. Последний аудит: `ls -t ~/.claude/insta-kit/audit-*.md | head -1` (если файла нет, предложи `ig-audit`, но не блокируйся). Из него возьми: форматы и формулы, которые работают (их можно повторять), и «бросить» (исключить), 3 гипотезы на проверку.
4. Последний свайп-файл `~/.claude/insta-kit/swipe-*.md` (из `ig-viral`): идеи, формулы хуков лидеров.
5. Спроси или возьми из аккаунта часовой пояс (по умолчанию Asia/Bishkek, UTC+6), стартовую дату (понедельник ближайшей недели) и сколько публикаций в неделю (по умолчанию 6 постов + сторис каждый день; день без поста допустим, тогда формат `stories`).

Если нет ни аудита, ни свайпа, скажи, что план на общих правилах, и предложи сначала `ig-audit` (свои цифры) и `ig-viral` (идеи).

## 1. Правила плана
- **Баланс форматов** (от числа постов): рилсы 60-70%, карусели 20-30%, остальное фото или пост-сторис. Сторис каждый день (опрос, закулисье, ответ на вопрос, напоминание о рилсе), это не пост.
- **Не повторять формат два дня подряд**, кроме формата, который аудит прямо назвал рабочим (передай его в `repeat_ok`).
- **Время**: если в аудите есть лучшие часы, бери их; иначе вечер (19:00-21:00 по времени аудитории) в будни и день в выходные, и сделай первые две недели тестом разных слотов.
- **Цель одна на пост**: `reach` (охват, рилсы по трендовой теме), `saves` (сохранения, карусели-чек-листы), `leads` (заявки в директ, кейс или демонстрация с кодовым словом). Не больше 1-2 постов недели с целью `leads`.
- **Один призыв**: одно действие в одном предложении (сохрани, перешли, напиши СЛОВО в директ). Кодовое слово только там, где цель `leads` (и только одно на неделю).
- **Хук рилса**: формула из `skills/ig-reel/hooks.json` (id и название); формулы не повторяются подряд, берутся из «повторить» аудита и из свайпа. Тему хука на этом шаге не пиши целиком, достаточно темы и формулы: полный сценарий делает `ig-reel`.
- **Делает скилл**: Reels с говорящей головой: `ig-reel` (сценарий) + `ig-cut` (монтаж) или `ig-shorts` (нарезка из длинного); рилс без съёмки: `ig-reel` + `ig-video`; карусель: текст и подпись через `ig-caption` (слайды пока пишутся вручную, отдельного скилла нет); сторис: свободный текст; чистка текстов: `ig-human`. Публикация: `ig-publish`, отдельным шагом по «да».
- **10 аккаунтов для комментариев**: 4-5 конкурентов из `competitors` и 5-6 из ниши (где сидит целевая аудитория, не только коллеги); из свайпа можно взять авторов залётных рилсов. 5 минут в день: содержательный комментарий, а не «огонёк».
- **Проверь, что не повторяются темы** прошлой недели (посмотри предыдущий `plan-*.md`, если есть).

## 2. Вывод
Составь план как JSON (формат и пример: `tests/fixtures/plan.json` в плагине, поля описаны в начале `plan.py`) и сохрани во временный файл. Прогони проверку и красивую таблицу:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-plan/plan.py" план.json --md план.md --csv план.csv
```
Запасной путь, если скилл скопирован в `~/.claude/skills`: `python ~/.claude/skills/ig-plan/plan.py ...`. Скрипт печатает таблицу (день, время, формат, тема, формула хука, цель, призыв, скилл, сторис), 10 аккаунтов и предупреждения: доли форматов, повтор формата два дня подряд, неизвестный hook_id, нет призыва или кодового слова при цели `leads`, не 10 аккаунтов. Исправь все предупреждения (или объясни, почему оставляешь) и прогони снова. Без Python таблицу можно собрать вручную по тем же столбцам.

Покажи пользователю таблицу и коротко: почему такой микс, на какие данные аудита и свайпа опирался, какую гипотезу план проверяет. Спроси: «Сохранить план? Какой пост делаем первым?»

## 3. Сохранение
Только после «да»: `~/.claude/insta-kit/plan-<ГГГГ-ММ-ДД>.md` (дата старта недели). Запись `--md` скрипта подходит как есть; CSV по желанию для таблиц и планировщиков. Следующий шаг: первый пост плана превращаем в сценарий (`ig-reel`), пользователь выбирает, с какого начать.
