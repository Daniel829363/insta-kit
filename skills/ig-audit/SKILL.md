# ig-audit: разбор своих постов по делу, а не по лайкам

Отвечай по-русски. Ничего не публикуй и не меняй в аккаунте. Только читай статистику.

## 0. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` (выбери аккаунт, возьми `key` и `composio_account`). Если файла нет, спроси аккаунт и предложи создать его по `templates/accounts.example.json`. Файл голоса `voice-<key>.md` для аудита не нужен: не блокируйся на нём (он понадобится позже, для `ig-reel`).

## 1. Данные: свои последние 20-50 постов
**А. Одна команда (Composio, свои аккаунты).** Сборщик сам ходит в Composio: ищет `composio` в PATH, иначе через `wsl -d Ubuntu -u root -- bash -lc`; листает страницы, запрашивает нужные поля и метрики по типу поста (рилсы: views, reach, saved, shares, ig_reels_avg_watch_time; карусели и фото: без времени просмотра), читает ответ, сохранённый Composio в файл, и пишет CSV для audit.py:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-audit/collect.py" --account <key или ca_...> --out посты.csv --limit 50
```
Длительность рилса берётся ffprobe по `media_url` (нужен ffprobe в PATH; флаг `--no-duration` отключает). Если ffprobe нет, колонка пустая, и audit.py считает только среднее время просмотра в секундах, без % досмотра. Только чтение. Если нужного поля нет в ответе, схема: `composio execute <TOOL> --get-schema`.
**Б. Без Composio**: пользователь вставляет таблицу из Meta Business Suite или CSV. Допустимы колонки на русском (минимум: охват, сохранения, пересылки, тип, дата).

## 2. Расчёт
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-audit/audit.py" посты.csv --top 5
```
Запасной путь для скопированного скилла: `python ~/.claude/skills/ig-audit/audit.py ...`.
Скрипт ранжирует: (1) по кратности охвата к медиане (ко всем постам и внутри типа: рилсы, карусели, фото), (2) по (сохранения + пересылки) на 1000 охвата только для постов с охватом не ниже max(50, 0.3 медианы), чтобы мелкие охваты не давали ложных лидеров, (3) по досмотру (среднее время просмотра / длительность; без длительности: среднее время в секундах). Посты младше 7 дней выводятся отдельным блоком «рано судить» и в «бросить» не попадают, в медианы не входят. Худшие по охвату (внутри типа): кандидаты «бросить».

## 3. Выводы
Не оценивай по лайкам. Сравнивай рилсы с рилсами, карусели с каруселями. Блок «рано судить» не трактуй как провал. Пересылки и сохранения означают ценность, досмотр означает удержание, охват означает дистрибуцию. Ответ в формате:
- **Повторить:** 2-3 паттерна (тема, формула хука из `skills/ig-reel/hooks.json`, длительность, формат) с доказательствами (цифры).
- **Бросить:** 2-3 паттерна с цифрами.
- **3 гипотезы на 2 недели:** каждая: что меняем, какую метрику ждём, на сколько (например, «досмотр с 35% до 50%»), сколько постов нужно для проверки.
- Если данных мало (< 15 постов) или разброс мал, честно скажи, что выводы предварительные.
Предложи следующий шаг: найти идеи у конкурентов (`ig-viral`) или сразу писать сценарий (`ig-reel`). Сохрани отчёт в `~/.claude/insta-kit/audit-<ГГГГ-ММ-ДД>.md` только после «да».
