# ig-audit: разбор своих постов по делу, а не по лайкам

Отвечай по-русски. Ничего не публикуй и не меняй в аккаунте. Только читай статистику.

## 0. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` (выбери аккаунт, возьми `composio_account`) и `~/.claude/insta-kit/voice-<key>.md`. Если файлов нет, спроси и предложи создать.

## 1. Данные: свои последние 20-50 постов
**А. Composio CLI** (свои аккаунты). Если `composio` не найден в PATH, попробуй `wsl -d Ubuntu -- bash -lc "composio ..."`. Схема инструмента: `composio execute <TOOL> --get-schema`. Аккаунт: флаг `--account <composio_account>`.
1. `composio execute INSTAGRAM_GET_USER_INFO ...` : базовая информация и число подписчиков.
2. `composio execute INSTAGRAM_GET_IG_USER_MEDIA ...` (ig_user_id `"me"`): последние посты, ссылки, подписи, тип, дата.
3. Для каждого поста `composio execute INSTAGRAM_GET_IG_MEDIA_INSIGHTS ...` : метрики `views`, `reach`, `saved`, `shares`, `likes`, `comments`, для рилсов `ig_reels_avg_watch_time` (миллисекунды).
Собери CSV со столбцами: `id,url,caption,type,duration,reach,saved,shares,likes,comments,avg_watch,timestamp`.
**Б. Без Composio**: пользователь вставляет таблицу из Meta Business Suite или CSV. Допустимы колонки на русском.

## 2. Расчёт
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-audit/audit.py" посты.csv --top 5
```
Запасной путь для скопированного скилла: `python ~/.claude/skills/ig-audit/audit.py ...`.
Скрипт ранжирует: (1) по кратности охвата к медиане аккаунта, (2) по (сохранения + пересылки) на 1000 охвата, (3) по досмотру (среднее время просмотра / длительность). Худшие по охвату: кандидаты «бросить».

## 3. Выводы
Не оценивай по лайкам. Пересылки и сохранения означают ценность, досмотр означает удержание, охват означает дистрибуцию. Ответ в формате:
- **Повторить:** 2-3 паттерна (тема, формула хука из `skills/ig-reel/hooks.json`, длительность, формат) с доказательствами (цифры).
- **Бросить:** 2-3 паттерна с цифрами.
- **3 гипотезы на 2 недели:** каждая: что меняем, какую метрику ждём, на сколько (например, «досмотр с 35% до 50%»), сколько постов нужно для проверки.
- Если данных мало (< 15 постов) или разброс мал, честно скажи, что выводы предварительные.
Предложи следующий шаг: найти идеи у конкурентов (`ig-viral`) или сразу писать сценарий (`ig-reel`). Сохрани отчёт в `~/.claude/insta-kit/audit-<ГГГГ-ММ-ДД>.md` только после «да».
