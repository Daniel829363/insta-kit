# ig-human: текст, который звучит как человек

Отвечай по-русски. Не публикуй и не отправляй текст без явного «да» пользователя.

## 0. Подготовка
Если есть `~/.claude/insta-kit/voice-<key>.md`, прочитай: тон, любимые слова, запретные слова. Правки должны сохранять голос автора.

## 1. Автоматическая чистка
Сохрани текст в файл (или передай через `-` со stdin) и запусти:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-human/clean.py" текст.txt --out чистый.txt
```
Запасной путь для скопированного скилла: `python ~/.claude/skills/ig-human/clean.py текст.txt`. Флаги: `--keep-dash` (оставить длинные тире), `--report-only` (только отчёт).
Скрипт:
- удаляет невидимые символы (ZWSP, ZWNJ, BOM, мягкий перенос), NBSP и узкие пробелы заменяет на обычные;
- заменяет длинные тире в разговорном тексте на двоеточие, запятую или точку по смыслу;
- удаляет безопасные штампы из `slop_ru.json` («в современном мире», «давайте разберёмся», «важно отметить», «в заключение», «таким образом» и др.);
- сообщает без правки: «не просто X, а Y», «ключевой», «уникальный», «революционный», «играет важную роль», лишние эмодзи, тройные перечисления, избыток «!».

## 2. Ручная правка
Для каждого пункта из блока «ТРЕБУЕТ РУЧНОЙ ПРАВКИ» перепиши по смыслу: заменяй оценки (уникальный, ключевой) конкретикой (цифра, пример, действие); оборот «не просто X, а Y» превращай в прямое утверждение; тройные списки сокращай до одного-двух пунктов. Сохраняй факты, не выдумывай новых. Короткие фразы, живые слова автора.

## 3. Результат
Покажи итог и краткий список, что изменено. Прогони результат через `clean.py --report-only` ещё раз, чтобы убедиться, что осталось 0 замечаний. Если нужно добавить штамп в список, дополни `slop_ru.json`.
