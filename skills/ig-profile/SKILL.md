# ig-profile: оценка профиля и переписанные варианты

Отвечай по-русски. Ничего не меняй в аккаунте сам: варианты показываешь, внедряет пользователь.

## 0. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` и `~/.claude/insta-kit/voice-<key>.md` (ниша, аудитория, тон, запретные слова, кодовое слово). Если нет, спроси и предложи создать.

## 1. Данные о профиле
- Свой аккаунт: `composio execute INSTAGRAM_GET_USER_INFO` (с `--account <composio_account>`; при отсутствии `composio` в PATH: `wsl -d Ubuntu -- bash -lc "composio ..."`) даёт имя, био, ссылку, число подписчиков. Сетку первых 9 постов даёт `INSTAGRAM_GET_IG_USER_MEDIA`.
- Чужой профиль (для примера): `mcp__apify__apify--instagram-profile-scraper`. Тратит кредиты Apify, спроси «да».
- Хайлайты и закреп через API не видны: попроси описание или скриншот.
- Без инструментов: попроси вставить имя, био, ссылку и список хайлайтов.

## 2. Оценка
Прочитай `${CLAUDE_PLUGIN_ROOT}/skills/ig-profile/rubric.json` (запасной путь: `rubric.json` рядом с этим файлом). 12 пунктов, максимум 100. По каждому: балл, причина в одну строку. Покажи таблицу «пункт, балл/макс, что не так». Итог: сумма из 100 и общий вердикт (0-49 переделать, 50-74 рабочий, 75+ сильный).

## 3. Что править: сначала то, что даст больше
Отсортируй пункты по `(max - балл) * impact` по убыванию (поле `impact` в рубрике). Для первых 4-5 пунктов дай по 2-3 готовых варианта:
- поле «Имя» с ключом поиска и городом;
- био, строка 1: «кому + что + результат» (до 30-40 символов на строку, без девиза);
- доказательство (цифра, кейс), призыв (одно действие), кодовое слово из voice-файла;
- идея закрепов и порядка хайлайтов (4-6 штук).
Проверь тексты на ИИ-штампы (скилл `ig-human`), избегай слов из списка запретных.

## 4. Итог
Покажи: оценку до, список правок по порядку, ожидаемый эффект. Спроси, что из этого утвердить; сам ничего не применяй.
