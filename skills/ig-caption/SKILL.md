# ig-caption: подпись, которая не режется в ленте

Отвечай по-русски. Ничего не публикуй без явного «да» пользователя.

## 0. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` и `~/.claude/insta-kit/voice-<key>.md` (тон, табу, кодовое слово, куда ведём). Если нет, спроси и предложи создать.

## 1. Написать или принять черновик
Если пользователь дал сценарий или идею, напиши подпись. Структура:
1. **Первая строка (до ~125 символов)**: крючок плюс ключевые слова для поиска Instagram (ниша, услуга, город): подпись индексируется поиском. Без приветствий.
2. Короткий абзац пользы или истории (1-3 предложения, абзацы разделены пустой строкой).
3. **Один призыв**: например, «Напиши КОД в директ, пришлю чек-лист». Если в voice-файле есть кодовое слово, используй его ровно в том регистре, как в автоответе.
4. 3-5 хештегов по теме (не 30), в конце.
Ссылки в подписи некликабельны: вместо них «ссылка в шапке профиля» или кодовое слово.

## 2. Проверка
Сохрани подпись в файл и запусти:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-caption/caption.py" подпись.txt --code КОД --keywords "карго из китая, доставка"
```
Запасной путь для скопированного скилла: `python ~/.claude/skills/ig-caption/caption.py ...`. Параметры `--code` и `--keywords` необязательны. Скрипт рисует рамку с первыми ~125 символами «как в ленте» и проверяет: крючок в первой строке, число призывов (нужно ровно одно), кодовое слово, длину (лимит 2200), абзацы, хештеги, ссылки. Исправь все «!!» и повтори.

## 3. Чистка ИИ-штампов
Прогони текст через `ig-human` (`python "${CLAUDE_PLUGIN_ROOT}/skills/ig-human/clean.py" подпись.txt`), примени автоматические правки и поправь ручные.

## 4. Выдача
Покажи итоговую подпись (с хештегами в конце) и как она будет выглядеть в ленте. Публикация только по явному «да» и по отдельной инструкции пользователя.
