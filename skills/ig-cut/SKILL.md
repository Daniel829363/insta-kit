# ig-cut: монтаж своего видео под Reels

Отвечай по-русски. Ничего не публикуй и не отправляй без явного «да» пользователя. Результат: готовый MP4 в отдельной папке, исходник не трогаем.

Скилл ведёт по проверенному пайплайну на внешнем скилле **ffmpeg-skill** (kajisho5/ffmpeg-skill, MIT). Сам он только маршрутизатор: все операции делают его скрипты.

## 0. Подготовка
1. Проверь, что ffmpeg-skill стоит: есть папка `~/.claude/skills/ffmpeg-skill/scripts/`. Если нет, скажи пользователю и предложи поставить:
   ```
   npx ffmpeg-skill
   ```
   (кладёт скилл в `~/.claude/skills/ffmpeg-skill`). Нужны FFmpeg 6.1+ в PATH (`ffmpeg -version`) и Python 3.10+. Если ffmpeg нет: Windows `winget install Gyan.FFmpeg`, macOS `brew install ffmpeg`, Linux через пакетный менеджер. Диагностика окружения: `python3 ~/.claude/skills/ffmpeg-skill/scripts/_contract.py doctor`.
2. Для субтитров и вырезания «э-э» нужна расшифровка: `pip install faster-whisper`. **Важно:** с `av` версии 16 и выше faster-whisper 1.2.x падает с ошибкой `metadata_errors`, поэтому: `pip install "av<16"`. Первая расшифровка скачает модель (сотни МБ), предупреди пользователя.
3. Скрипты запускаются так (на Windows, если `python3` нет, подойдёт `python`):
   ```
   FF="$HOME/.claude/skills/ffmpeg-skill/scripts"
   python3 "$FF/<tool>.py" ...
   ```
   Общие флаги: `--dry-run` (план без записи), `--json-brief`, `--overwrite`, `-o файл`. Полный список флагов: `python3 "$FF/<tool>.py" --help`.
4. Узнай у пользователя: файл, язык речи (по умолчанию ru), нужны ли субтитры, куда класть результат. Выходную папку делай новую (например, `reel-out/`), каждому шагу своё имя: `01_tight.mp4`, `02_916.mp4`, `03_captions.mp4`, `04_final.mp4`.
5. Посмотри, из чего исходник: `python3 "$FF/probe.py" файл.mp4` (длительность, разрешение, fps, звук). Планируй по реальным числам.

## 1. Вырезать паузы и «э-э»
```
python3 "$FF/silence.py" исходник.mp4 --transcribe --filler --filler-lang ru --speech-aware \
  --threshold -30 --min-silence 0.4 -o reel-out/01_tight.mp4 --overwrite
```
- `--filler` без `--transcribe` (или `--words файл.json`) не работает: скрипт ищет слова-паразиты по расшифровке.
- `--speech-aware` оставляет короткие вдохи внутри фразы, чтобы речь не звучала рублено.
- Порог `-30` дБ подходит для комнаты со средним шумом; тихая комната: `-40`, шумная: `-25`. Сначала можно `--list`: покажет паузы и план без записи.
- Если режет слишком агрессивно, увеличь `--min-silence` (0.6) и `--margin` (0.25).

**Сверка: слова не должны теряться.** Расшифруй исходник и результат (любой Whisper, например faster-whisper модель `small`, `language="ru"`) и сравни. Допустимы: ушедшие «э-э», «ну», «вот», одно слово-связка. Если пропали смысловые слова, пересними шаг с большим `--margin` и меньшим `--threshold` (например `-35`). Покажи пользователю длительность до и после.

## 2. Формат 9:16
```
python3 "$FF/fit.py" reel-out/01_tight.mp4 --aspect 9:16 --fit blur --width 1080 -o reel-out/02_916.mp4 --overwrite
```
`--fit blur`: кадр целиком по центру на размытой затемнённой копии, ничего не обрезается. Если герой в центре и кадр горизонтальный, можно `--fit crop` (с `--crop-x 0..1`, если человек не по центру). Источник ниже 720p будет увеличен и станет мягким: предупреди пользователя.

## 3. Субтитры по слову
```
python3 "$FF/caption.py" reel-out/02_916.mp4 --transcribe --language ru --animate pop --karaoke \
  --platform reels -o reel-out/03_captions.mp4 --write-srt reel-out/03_captions.srt --overwrite
```
- Слово подсвечивается по мере речи (`--karaoke`), появление `pop`. `--platform reels` ставит безопасные зоны Instagram (текст не залезает под интерфейс).
- Стиль: `--font`, `--size`, `--color`, `--highlight-color`, `--position`. Подгоняй под бренд из `voice-<key>.md`, если там есть.
- Прочитай `03_captions.srt`: исправь опечатки в именах и терминах (`--srt исправленный.srt` вместо `--transcribe`), потом прожги заново.

## 4. Громкость
```
python3 "$FF/loudness.py" reel-out/03_captions.mp4 -I -14 -o reel-out/04_final.mp4 --overwrite
```
Двухпроходная нормализация до -14 LUFS, пик не выше -1 dBTP, видео копируется без перекодирования.

## 5. Проверка перед публикацией
```
python3 "$FF/check.py" reel-out/04_final.mp4 --platform reels --content
```
Таблица PASS/WARN/FAIL: длительность, 9:16, 1080x1920, fps, кодек, цвет, громкость, чёрные кадры, замершая картинка, провалы звука, первый кадр. Любой FAIL исправь командой из колонки `fix` и повтори. Предупреждение про «subtitles: none» нормально: субтитры вшиты в картинку, а не лежат дорожкой.

## 6. Выдача
Покажи: путь к `04_final.mp4`, длительность до и после монтажа, итог `check` (сколько PASS/WARN/FAIL), что вырезано. Дай превью: кадр (`python3 "$FF/look.py" --help`) или кусок 10 секунд. Дальше подпись через `ig-caption`, публикация через `ig-publish` только после «да».

## Ограничения и заметки
- Всё локально, без облака; расшифровка Whisper на CPU для 1 минуты занимает порядка десятков секунд.
- Один сквозной прожиг субтитров: на каждом шаге видео перекодируется (x264, crf 18), поэтому порядок важен: сначала вырезка и 9:16, затем субтитры, затем громкость (она видео не трогает).
- Не работает на аудио-файлах и HDR без доп. флагов: в этом случае смотри `probe.py` и справку ffmpeg-skill (`references/workflow.md`).
