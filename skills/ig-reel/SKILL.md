# ig-reel: сценарий рилса с проверенным хуком

Отвечай по-русски. Ничего не публикуй и не отправляй без явного «да» пользователя. Результат: сценарий в чате (и файл по просьбе).

## 0. Подготовка
Прочитай `~/.claude/insta-kit/accounts.json` и `~/.claude/insta-kit/voice-<key>.md`: ниша, аудитория, тон, слова-табу, кодовое слово и куда ведём. Если нет файла, спроси и предложи создать. Если есть свайп-файл `~/.claude/insta-kit/swipe-*.md` (из `ig-viral`), возьми идеи оттуда.

## 1. Идея
Уточни за один вопрос (не допрос): о чём рилс, какой результат получит зритель, какая цифра или история есть, целевая длительность (по умолчанию 25-35 с), кодовое слово или призыв. Если идея размыта, предложи 3 угла.

## 2. Три хука
Прочитай `${CLAUDE_PLUGIN_ROOT}/skills/ig-reel/hooks.json` (запасной путь: рядом с этим файлом). Выбери 3 разные формулы из 26 (id и название), напиши под идею. Для каждого: **устный хук** (до 12 слов, лучше до 8) и **экранный хук** (до 6 слов, другой, чем устный).
Оцени:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-reel/hookscore.py" "хук 1" "хук 2" "хук 3"
```
Запасной путь: `python ~/.claude/skills/ig-reel/hookscore.py ...`. Оценка: >= 70 сильный, 50-69 средний, < 50 слабый. Штрафы выводятся с объяснением (приветствие, подводка, «стоп-скролл», вода, нет цифры, нет ставки). Слабые хуки перепиши и оцени снова; покажи пользователю лучший и 2 запасных с баллами. Дождись выбора, если пользователь хочет участвовать, иначе бери лучший.

## 3. Сценарий
Структура: хук (0-3 с) → ставка/обещание → 2-4 пункта пользы, в каждом конкретика (цифра, имя, сумма) → результат → призыв с кодовым словом (одно действие) → строка, возвращающая к началу (петля).
Правила: на «ты» (если так в voice-файле), короткие фразы (до 12-15 слов), смена кадра минимум каждые 3-4 секунды, ни одного приветствия, обещание из хука выполнить до середины.
Запиши сценарий построчно, по строке на бит: `устная строка | текст на экране`.

## 4. Тайминг и проверки
Сохрани строки во временный файл и запусти:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-reel/beats.py" сценарий.txt --target 30
```
Запасной путь: `python ~/.claude/skills/ig-reel/beats.py ...`. Скрипт считает тайминг (~150 слов/мин) и предупреждает: хук > 3 с, бит > 4 с, три строки подряд без конкретики, нет петли, длительность вне цели. Исправь замечания и прогони ещё раз.

## 5. Чистка ИИ-штампов
В конце прогони устный текст и подпись через `ig-human` (`python "${CLAUDE_PLUGIN_ROOT}/skills/ig-human/clean.py" файл.txt`), поправь найденное руками.

## 6. Выдача
Покажи: итоговый хук (с баллом), сценарий с таймкодами и экранным текстом, предложение по обложке и звуку, подпись (передай в `ig-caption`). Не публикуй: публикация только по явному «да» пользователя и по его отдельной инструкции.
