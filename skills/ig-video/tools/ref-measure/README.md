# ref-measure: разбор референса в цифрах

Смотрит чужой ролик (и, если надо, наш) и выдаёт «рецепт» монтажа цифрами: склейки, длина планов,
частота изменений в кадре и в центре, застывшие куски, первые 3 секунды, звук, свет и цвет. Плюс листы
кадров и карта событий. Движок: `hyperframes measure` (HeyGen HyperFrames 0.9.7, Apache-2.0). Ставится один раз вне плагина
(чтобы не стираться при обновлении): `npm i --prefix ~/.claude/insta-kit/hf hyperframes@0.9.7 --ignore-scripts`
(~110 МБ). Скрипт ищет его там или в `node_modules` рядом. Телеметрия и проверка обновлений выключены
переменными в скрипте; навсегда: `node ~/.claude/insta-kit/hf/node_modules/hyperframes/bin/hyperframes.mjs telemetry disable`.

## Запуск

```
python -I "${CLAUDE_PLUGIN_ROOT}/skills/ig-video/tools/ref-measure/refmeasure.py" REF.mp4 [--ours НАШ.mp4] [--out ПАПКА] [--start 0 --end 15] [--sheet-every 1]
```

Время: ~6 с на 50-секундный ролик. Результат в ПАПКЕ (по умолчанию `<ref>_measure`):
- `RECIPE.md`: таблица «референс / наш», плотность изменений по 5 с, планы, застывшие куски, советы;
- `measure.json`: все сырые цифры и события;
- `sheet_ref_N.jpg` / `sheet_ours_N.jpg`: кадр каждую секунду; `events_*.png`: карта событий.

Ролик скачать: `yt-dlp -o ref.mp4 <ссылка>` (Instagram/TikTok/YouTube).

## Что значат цифры

- **Событие**: появление, исчезновение, изменение, склейка или вспышка в одной из 16 клеток кадра (сетка 4×4,
  порог: средняя смена яркости 5 из 255). Плавное движение камеры внутри плана склейкой не считается.
- **Медиана паузы между изменениями**: наше правило монтажа — изменение каждые 0.3–0.5 с.
- **Центр**: 4 центральные клетки. Там должен двигаться главный объект; мелочь по краям не в счёт.
- **Застывшие куски**: промежутки ≥1 с без единого события. Мелкие изменения (галочка, цифра счётчика) могут
  не дотянуть до порога: проверять по листу кадров.
- **Количество движения** (`energy`): во сколько раз наш ролик движется больше или меньше (0.8–1.25 = так же).
- **Свет/цвет** (`look`): яркость, контраст, насыщенность, теплота — чтобы попасть в «настроение» референса.

## Отдельные команды движка (для точечного разбора)

```
set HYPERFRAMES_NO_TELEMETRY=1
node ~/.claude/insta-kit/hf/node_modules/hyperframes/bin/hyperframes.mjs measure <команда> --help
```
- `curve --start 3 --end 4 --roi x,y,w,h` — кривая одного движения: старт, длительность, перелёт, ближайший ease
  (перевести в spring/interpolate Remotion; `--compare наш.mp4` сравнит с нашей копией);
- `ink --at 2.5 --roi …` — размер текста и строк в пикселях;
- `frames --range 3,4` — подряд все кадры участка (разобрать переход); `frames --events` — полоски на каждое окно событий;
- `extract --at 5 --roi …` — вырезать кадр или кусок; `face`, `sync` — лицо и липсинк.
