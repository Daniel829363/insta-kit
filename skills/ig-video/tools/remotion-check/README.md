# remotion-check — предрендерная проверка Remotion-композиций

Перенос идей `hyperframes check` (HeyGen HyperFrames, Apache-2.0, см. `NOTICE`) на Remotion.
Композиция открывается в настоящем Chrome так же, как это делает рендерер Remotion (`bundle()` → статический сервер →
`makePage()` → `seekToFrame()`), на выбранных кадрах запускаются DOM-проверки, а по готовому MP4 — проверки через ffmpeg.
**Проекты менять не нужно**: все `@remotion/*` берутся из `node_modules` самого проекта, своих зависимостей у инструмента нет.

## Запуск

```
node "${CLAUDE_PLUGIN_ROOT}/skills/ig-video/tools/remotion-check/check.mjs" --project <папка проекта> --comp <CompositionId> [опции]
```

Список композиций проекта: `npx remotion compositions` (или смотрите `Root.tsx`).

| Опция | Что делает |
|---|---|
| `--props file.json` | input props композиции |
| `--samples 0.25s` / `--samples N` | шаг выборки (по умолчанию 0.25 с) или N равномерных кадров |
| `--from S --to S` | диапазон в секундах (проверки «финальная строка» при `--to` < длины отключаются) |
| `--reels-safe` / `--reels-safe=strict` | зоны интерфейса Instagram Reels (см. ниже) |
| `--caption-zone x0,y0,x1,y1` | своя зона: доли 0..1 или px |
| `--video file.mp4` | проверки готового MP4 (громкость, true peak, тишина, заморозка, первый кадр) |
| `--json out.json` | полный отчёт в JSON (включая все элементы кластеров) |
| `--sheet out.jpg` | контактный лист проблемных кадров, проблемные боксы — красным |
| `--report out.txt` | текстовый отчёт в файл (на экран выводится всегда) |
| `--entry path` | entry-файл (по умолчанию `src/index.ts`) |
| `--bundle dir` | готовый бандл (иначе собирается во временную папку, rspack/webpack — как в `remotion.config.ts`) |
| `--contrast-samples N` | сколько кадров проверять на контраст (по умолчанию 16; шрифты проверяются на каждом кадре) |
| `--no-contrast`, `--no-fonts`, `--no-cache`, `--quiet` | отключить проверку / кеш сборки / прогресс |
| `--sheet-max N` | макс. кадров в листе (18) |

Код выхода: `1` — есть ошибки, `0` — нет, `2` — неверные аргументы, `3` — композицию не удалось открыть.
Типичный вызов для Reels:

```
node check.mjs --project D:\proj\video --comp MyReel --reels-safe --video out\reel.mp4 --sheet out\check.jpg --json out\check.json
```

Скорость (RTX 5060, Windows): 65-секундный ролик при шаге 0.25 с (261 кадр) — ~46 с, 24-секундный — ~12–16 с
(≈0.15 с на кадр + 10–15 с на старт; первый бандл ~10 с, потом кеш).

## Уровни

* **ОШИБКА** — почти наверняка дефект (код выхода 1). **ПРЕДУПРЕЖДЕНИЕ** — стоит посмотреть. **ИНФО** — кратковременное
  (один сэмпл — как у HyperFrames, «переход/анимация») или заведомо возможный приём дизайна; в отчёте схлопывается по кодам.
* Персистентность (как в HyperFrames): проблема, замеченная лишь в одном сэмпле, понижается до «инфо». Для остальных
  «держится» = самый длинный непрерывный отрезок. Однотипные находки в один момент склеиваются в кластер
  («Ещё 108 однотипных…»); полный список — в JSON (`items`).

## Проверки, пороги и как исправить

Допуск геометрии везде 2 px (как в HyperFrames).

| Код | Что ищет | Порог / уровень | Как исправить |
|---|---|---|---|
| `text_box_overflow` | текст выходит за ближайший контейнер (clip или блок с фоном/рамкой/паддингом) | выход > 2 px; ошибка при ≥ 0.4 с подряд | расширить контейнер до указанного размера, уменьшить шрифт до рассчитанного, разрешить перенос строк |
| `clipped_text` | текст обрезан `overflow:hidden` собственного блока (`scrollWidth > clientWidth`) | > 2 px; ошибка при ≥ 0.4 с | увеличить блок / убрать overflow (`text-overflow: ellipsis` не считается) |
| `canvas_overflow` | текст выходит за кадр | инфо; предупреждение: выход ≥ 10 px и ≥ 0.4 с; ошибка: ≥ 5% короткой стороны и ≥ 1 с (**отличие от HF:** у них максимум «предупреждение») | сдвинуть внутрь, ограничить ширину; для намеренного выезда `data-layout-allow-overflow` |
| `text_at_edge` | текст вплотную к краю (≤ 2 px, не выходя) | предупреждение при ≥ 0.4 с | добавить поля |
| `container_overflow` | дети клипующего контейнера выступают за него (SVG пропускается) | выход > 2 px | изменить размеры; для маски-анимации `data-layout-allow-overflow` |
| `content_overlap` | два сплошных текста пересекаются > 20% меньшего блока, по глифам (учёт line-height < 1), без пар из одного flex/grid | предупреждение ≥ 0.5 с; ошибка: ≥ 50% и оба HTML | разнести по зонам; намеренное — `data-layout-allow-overlap` |
| `text_occluded` | поверх текста лежит непрозрачный элемент (сетка 3×9 точек `elementsFromPoint`, `pointer-events` на время проверки включаются) | покрыто < 10% — инфо; 10–50% или SVG-слой — предупреждение; ≥ 50% и HTML-элемент — ошибка | поднять по z-index, дать свою зону; намеренное — `data-layout-allow-occlusion` |
| `text_not_painted` | текст с прозрачной заливкой (`color`/`-webkit-text-fill-color`), без stroke/shadow/`background-clip:text` | ошибка | задать непрозрачный `color` |
| `text_not_painted_ghost` | текст смонтирован ≥ 1 с (≥ 4 сэмплов), но ни разу не был виден (opacity≈0, нулевой размер, за кадром, clip-path) | предупреждение (opacity/size ≥ 3 с), иначе инфо | проверить анимацию появления / Sequence |
| `safe_zone` | текст в зоне (`--caption-zone`, `--reels-safe`) | ≥ 25% площади текста и ≥ 50% текста на кадре; ≥ 0.4 с — предупреждение | сдвинуть из зоны; нижние титры — `data-layout-allow-caption-zone` |
| `contrast_aa` | контраст WCAG AA: цвет текста против медианы пикселей фона (цвет текста на время скриншота прячется; stroke учитывается) | обычный 4.5:1, крупный (≥ 24 px или ≥ 19 px bold) 3:1; ошибка — провал в ≥ 2 проверенных кадрах, иначе предупреждение | заменить цвет на предложенный (проходит порог) или изменить фон. Одинаковый цвет у многих текстов склеивается; text-shadow или «в другие моменты контрастный» → инфо |
| `line_unread` | строка ≥ 30 px высотой (при 1080) на экране меньше порога | 1–2 слова: 0.4 с; иначе ¾·(0.5 с + 0.3 с × слов); последняя строка ролика ≥ 2 с. Окно уточняется бисекцией (±8 мс) | держать строку ≈ 0.5 с + 0.3 с на слово |
| `subtitle_stream` | эвристика «субтитры по слову» (см. ниже) | предупреждение: медиана < 0.2 с или ≥ 2 строк < 0.1 с, иначе инфо | показывать слово ≥ 0.25 с |
| `text_below_floor` | текст мельче 2.6% короткой стороны (28 px при 1080) дольше 0.5 с, с учётом scale/transform | предупреждение; одна сводка со списком | кегль ≥ 28 px; «текстура» — `data-layout-ignore` |
| `first_frame_empty` | на кадре 0 нет ни текста, ни медиа, либо кадр однотонный (σ < 3) | предупреждение | показать заголовок/образ на 0-м кадре |
| `dead_stretch` | картинка не меняется > 3 с (по миниатюрам: < 0.15% пикселей изменилось на > 12/255 и средняя разница < 0.35) | предупреждение; последние 3 с не считаются | запустить движение в пределах 3 с |
| `film_silent` | DOM: нет `<audio>/<video>` (только инфо!); MP4: тишина > 15 с или нет звука | MP4 — предупреждение | музыка/звуки действий |
| `font_not_loaded`, `font_glyph_fallback` | реальные шрифты узла через CDP `CSS.getPlatformFontsForNode`: заявленный шрифт не загружен / часть глифов отрисована запасным | ошибка (нет глифов букв/цифр); символы ▌♥→✓ — инфо; эмодзи игнорируются | подключить subset: `loadFont('normal',{subsets:['latin','cyrillic','cyrillic-ext']})` — **буквы ң ө ү есть только в `cyrillic-ext`** |
| `missing_asset`, `console_error` | `Network.loadingFailed` / HTTP ≥ 400, `console.error`, необработанные исключения во время seek | ошибка (`ERR_CACHE_MISS`/`ERR_ABORTED` игнорируются) | путь в `staticFile()`, регистр, кириллица в имени |
| MP4: `loudness`, `true_peak` | ebur128 | −14 ±1.5 LUFS; true peak ≤ −1 dBTP | `loudnorm=I=-14:TP=-1.5` / `alimiter` |
| MP4: `silence_gap`, `dead_stretch`, `first_frame_empty` | silencedetect (−50 dB), freezedetect (−60 dB, 3 с), signalstats кадра 0 | пауза ≥ 4 с — инфо | — |

### Зоны интерфейса Reels (`--reels-safe`, 1080×1920, масштабируются по размеру кадра)
Типовые значения: **верх 220 px, низ 380 px, право 140 px** (верхняя панель, подпись/кнопки внизу, колонка лайк/коммент справа).
`--reels-safe=strict` — консервативные значения из рекомендаций Meta для рекламы в Reels: верх 14% (≈270 px), низ 35% (≈670 px), края 6% (≈65 px).
Значения взяты из памяти/практики и **не сверялись онлайн в этой сессии** — интерфейс Instagram меняется; правятся в `check.mjs`
(блок «зоны»). Зоны считаются для текста, а не для картинки.

### Эвристика субтитров «по слову» (karaoke)
* Подсвеченное слово внутри **одной постоянно видимой строки** (как у нас: чип на слове) — это один блок, `line_unread` не срабатывает.
* Если слова приходят **по одному новыми элементами**, среди провалившихся кандидатов ищется «поток»: ≥ 4 коротких (≤ 3 слов)
  строк с одной позицией (по сетке 12% × 6% кадра) и кеглем (±6 px). Они не дают отдельных предупреждений, вместо этого — одна запись
  `subtitle_stream` со статистикой (медиана / минимум). Иконки, инициалы и счётчики (меньше 2 букв, нет слова из ≥ 2 букв) в `line_unread` не участвуют.
* Ограничение: чат-пузыри в одной позиции тоже могут сойтись в «поток» (это только инфо).

## Чем отличается от HyperFrames

* DOM Remotion вместо HF-композиции: корень `#remotion-canvas`, нет `data-start/data-composition-id`; соответствия флагам
  `data-layout-*` оставлены (`data-layout-ignore`, `-allow-overflow`, `-allow-overlap`, `-allow-occlusion`, `-allow-caption-zone`;
  также `data-rc-ignore`, `data-rc-allow-*`) — их можно вешать на элементы прямо в JSX.
* Добавлено: шрифты, Reels-зоны, «призрачный» текст, поток субтитров, кластеризация, видео-проверки ffmpeg, пиксельный `dead_stretch`.
* Смягчено: наложения/перекрытия внутри SVG-иллюстраций и перекрытия непрозрачными SVG-слоями — не выше предупреждения;
  декоративные символы (♥ ✓ ↓ •) не участвуют в проверках вёрстки; одиночный сэмпл → инфо.

## Известные ограничения (честно)

* **Много ложных срабатываний на анимационных роликах.** Слои, «кучи» пузырей, камера по SVG-миру, текст, уезжающий за кадр, —
  намеренные приёмы, а проверка видит только геометрию. В нашей выборке (3 ролика) около половины ошибок и большинство
  `line_unread`/`text_occluded`/`canvas_overflow` — намеренный дизайн. Надёжные (детерминированные) проверки: шрифты, первый кадр,
  контраст статичного текста, мелкий текст, safe-зоны, громкость, пропавшие ресурсы.
* Выборка с шагом: события короче шага (0.25 с) могут пропуститься; `line_unread` уточняется бисекцией, остальное — нет.
  Для коротких ошибок используйте `--samples 0.125s`.
* Видны только DOM-текст и SVG `<text>`. Текст внутри `<canvas>`/WebGL/видео не проверяется; пиксели canvas не читаются.
* Контраст — по медиане пикселей под рамкой текста; для текста поверх меняющегося видео/градиента это приближение;
  outline через `text-shadow` не пересчитывается (элемент с text-shadow понижается до инфо).
* `dead_stretch` по миниатюрам не видит очень мелкое движение (< 0.15% площади кадра, например моргающий курсор);
  на готовом MP4 для этого есть freezedetect.
* `film_silent` по DOM ненадёжен (звук подмешивается ffmpeg снаружи или через Web Audio) — поэтому только инфо; нужен `--video`.
* Использует внутренние модули `@remotion/renderer` (`make-page`, `seek-to-frame`): проверено на Remotion **4.0.537**; на других версиях
  может потребоваться правка `lib/remotion.mjs`. Если Remotion не найден в проекте — инструмент не стартует.
* При «перемотке» React может пересоздать DOM-узел; части сопоставляются по селектору/тексту, а не по идентичности узла.
* Фикстура старого бага Nunito (`tests/make-oldbug-fixture.sh`) создаёт junction `node_modules`. **Удалять его только**
  `cmd /c rmdir <путь>` — иначе (рекурсивное удаление) можно стереть чужой `node_modules`.

## Структура

```
check.mjs          — CLI, обход кадров, сбор результатов, лист, JSON
lib/remotion.mjs   — bundle → сервер → Chrome → makePage → seek, CDP-обёртки
lib/page-audit.js  — скрипт, выполняемый внутри страницы (layout / craft / contrast / fonts / overlay / sheet)
lib/analyze.mjs    — персистентность, line_unread, dead_stretch, контраст, шрифты, кластеры
lib/video.mjs      — ffmpeg-проверки MP4
lib/report.mjs     — отчёт на русском
tests/<проект>/    — report.txt, report.json, sheet.jpg по тестовым роликам
```
