# Монтаж «объяснялки без человека»: приёмы, которые держат досмотр

Справочник для `ig-video`. Читай перед версткой сцен. Цель: зритель не успевает заскучать,
каждая мысль озвучки видна на экране как действие, а не как статичная картинка.

## 10 правил
1. **Что-то меняется каждые 0.3–0.5 с.** Кадр никогда не стоит: зум, поворот, карусель, растущая
   диаграмма, счётчик, влёт элемента, смена цвета. Кадр, где меняется только титр, — место, где
   уходят. Камера всегда в лёгком движении (медленный наезд/дрейф/поворот 1–2°) даже внутри сцены.
   **Перечисления** («подписи, план, профиль») — каждый пункт своя быстрая вспышка ≈0.3 с со
   сменой цвета/позиции; однотипное не держать. Элементы уже на месте, когда камера прилетает.
2. **Причина → следствие на экране.** Команда в терминале → пунктир к телефону → курсор нажимает
   → интерфейс меняется (плитка, счётчик, статус). Зритель видит, что инструмент *делает*.
3. **Курсор как рука.** Наводит, кликает (рябь на клике), кнопка меняет состояние
   («Забрать →» → зелёная «✓»). Курсор заменяет живого ведущего.
4. **Морфинг вместо склейки.** Один объект превращается в следующий: сетка постов → столбики
   графика → столбик-выброс → карточка рилса → переворот в карточку формулы.
5. **Счётчики и печать.** Числа крутятся с плавной остановкой (0 → 11, 52 → 43 с, 00:00 → 60:00),
   текст печатается с курсором, пустые поля в шаблоне заполняются.
6. **Штампы с ударом.** «СИЛЬНЫЙ», «СРАБОТАЛО», «69×»: влёт с поворотом, scale 1.4 → 1 и лёгкая
   тряска 2–3 кадра. Не больше одного штампа на сцену.
7. **Предмет-метафора на каждую мысль.** «Старые видео» — коробка «архив» открывается;
   «до съёмки» — телефон на штативе; «команда в одном чате» — рабочие места вокруг терминала;
   «формулы хуков» — 3D-лента карточек. Метафора понятна без слов.
8. **Переходы.** Между соседними мыслями — пролёт камеры по холсту по видимому пунктиру
   (≤ 0.4 с, без пустых кадров). Между разделами — шторка акцентного цвета (≈ 0.4 с) с
   градиентным краем. Один раз за ролик — вспышка/блюр на входе в главную часть.
9. **Фоновая жизнь.** Точечная сетка с лёгким параллаксом, парящие частицы, элементы «дышат»
   (scale 1 → 1.02), мягкие тени. Без этого холст выглядит мёртвым.
10. **Титр неприкосновенен.** 2 строки сверху, несказанные слова бледные, сказанные тёмные,
    ключевое — в плашке акцентного цвета. Макеты никогда не наезжают на титр.

## Подача набора инструментов
Если продукт — набор (скиллы, функции), подавай его как **команду агентов**: один плагин
«раскрывается» в N агентов с ролями (разведчик, аналитик, сценарист, монтажёр…), сцена «команда
вокруг одного чата», через весь ролик бейдж «агент №N». Иначе зритель думает «поставил одну штуку».

## Карта сцен (шаблон под ролик-обзор инструмента)
| Мысль в озвучке | Что на экране |
|---|---|
| Хук с цифрой | отъезд-наезд на телефон, вокруг вылетают уведомления; бейдж роли зачёркивается и меняется; карточки функций веером со счётчиком |
| «Бесплатно / безопасно» | терминал печатает установку (адрес скрыт), прогресс-бар, бейджи «open source», «без твоего да ничего не публикуется» |
| Функция «находит» | радар со сканирующим лучом → график с медианой, столбик взлетает с обрывом оси, штамп кратности |
| Функция «разбирает» | сетка → столбики; ненужная метрика зачёркивается, нужные прилетают чипами; круг-прогресс |
| Функция «пишет/оценивает» | лента карточек, три выходят вперёд, баллы печатаются, штамп на лучшей |
| «Главное» | шторка + крупное слово с блюр-входом по буквам |
| Монтаж | таймлайн с волной: паузы и «э-э» подсвечиваются и схлопываются; субтитры по слову; шкала громкости до −14 LUFS; ножницы режут видео на шортсы |
| Мета-момент «как этот ролик» | быстрый (≈1 с) отъезд на всю карту сцен и сразу обратно |
| Призыв | телефон: комментарий с кодовым словом печатается → директ прилетает → курсор жмёт кнопку → «✓»; вокруг орбитой чипы-итоги |

## Призыв через кодовое слово
Если ссылка выдаётся по кодовому слову, **в ролике не показывай адрес, ник владельца и команду
установки** (размой или замени точками): иначе зритель найдёт сам и не напишет комментарий.

## Озвучка под этот формат
- Голос похожий на образец: `POST https://api.elevenlabs.io/v1/similar-voices` (multipart
  `audio_file` 20–40 с, `top_k`) возвращает голоса библиотеки ElevenLabs. Чужой голос не клонируй.
- Не ускоряй готовую озвучку (atempo звучит хуже): если ролик длинный, сокращай текст.

## Проверка перед выдачей
Сетка кадров каждые 0.5–1 с (`ffmpeg -vf "fps=2,scale=300:-1,tile=6x5"`): нет пустых кадров,
ничего не наезжает на титр, мелкий текст ≥ 34 px, важное вне зон интерфейса Reels
(верх 250 px, низ 400 px).
