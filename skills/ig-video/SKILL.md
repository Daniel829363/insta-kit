# ig-video: ролик без съёмки

Отвечай по-русски. Ничего не публикуй и не отправляй без явного «да» пользователя. Платные шаги (озвучка тратит кредиты ElevenLabs) подтверждай до запуска.

Всё необязательное: каждому шагу нужно своё, и скилл сам говорит, чего не хватает.

| Нужно | Для чего | Как проверить / поставить |
|---|---|---|
| Ключ ElevenLabs в `ELEVENLABS_API_KEY` | озвучка | elevenlabs.io/app/settings/api-keys; Free-аккаунт даёт только некоммерческое использование, для рекламы нужен платный тариф |
| Node.js 18+ и Remotion | рендер графики | `node -v`; проект `npx create-video@latest`; скилл `remotion-best-practices`, если установлен, читай перед кодом |
| FFmpeg 6.1+ | нарезка звука, сведение, громкость | `ffmpeg -version` |
| ffmpeg-skill | проверка перед публикацией | см. `ig-cut` (`npx ffmpeg-skill`) |

## 1. Идея и сценарий
Прочитай `~/.claude/insta-kit/accounts.json` и `voice-<key>.md` (тон, табу, кодовое слово). Уточни одним вопросом: о чём ролик, для кого, какая цифра или результат, длительность (30-45 с), призыв. Сценарий пиши по `ig-reel`: 3 хука, оценка `hookscore.py`, построчный сценарий `устная строка | текст на экране`, проверка `beats.py`. Прогони устный текст через `ig-human`.

Для озвучки подготовь файл `voice.txt`: **одна строка = одна фраза**, без экранного текста. Аббревиатуры и английские слова пиши так, как они звучат по-русски («Ватсап», «Эксель», «Эй-Пи-Ай»). Для `eleven_v3` в начале строки можно ставить тег эмоции: `[excited]`, `[confident]`, `[curious]`, `[frustrated]`. Фразы с «!» иногда дают кашу без тегов: перепроверяй расшифровкой.

## 2. Озвучка (ElevenLabs, один запрос)
Сначала посмотри запрос и цену, ничего не вызывая:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-video/tts_elevenlabs.py" voice.txt --voice-id <voice_id> --dry-run
```
Запасной путь для скопированного скилла: `python ~/.claude/skills/ig-video/tts_elevenlabs.py ...`. Число символов = число кредитов. Назови его пользователю и дождись «да». Потом:
```
python "${CLAUDE_PLUGIN_ROOT}/skills/ig-video/tts_elevenlabs.py" voice.txt --voice-id <voice_id> --out-dir voice-out --name voice [--model eleven_v3] [--seed 7] [--split-lines]
```
- Модель по умолчанию `eleven_v3` (эмоции через теги); `--model eleven_multilingual_v2` спокойнее и стабильнее. Язык `ru`.
- **Весь текст уходит одним запросом.** Урок: озвучка по фразам даёт резкие склейки интонации. Поэтому не гонять строки по одной.
- Результат: `voice.mp3`, `voice.words.json` (слова с `start`/`end` в секундах, номера строк, общая длительность) и `voice.alignment.json` (сырое посимвольное выравнивание). Теги эмоций из слов убираются.
- `--split-lines` дополнительно режет дорожку на `voice_NN.wav` по строкам (по паузам между фразами, фейды 15/60 мс; нужен ffmpeg). Нужен, если сцены в Remotion привязаны к отдельным аудиофайлам; для сплошной дорожки не нужен.
- `voice_id` берётся из библиотеки голосов ElevenLabs (премейд-голоса доступны сразу, библиотечные через API требуют платного тарифа). Не записывай ID и ключи в файлы проекта, которые уйдут в публичный репозиторий.
- Проверь результат: расшифруй mp3 (Whisper) и сравни с текстом. Ошибка в ударении или слове: поправь написание в `voice.txt` и повтори (снова платно, предупреди).
Покажи пользователю mp3 (отправь файл) и жди «ок» до верстки: переделывать озвучку после анимации дороже.

## 3. Формат «объяснялка без человека»
- Холст 1080x1920, 30 fps, светлый фон, **один акцентный цвет** (из voice-файла или бренда) плюс нейтральные.
- **Титр сверху:** крупная фраза словами, которые подсвечиваются акцентом по мере речи (тайминги берёшь из `words.json`: слово активно, когда `start <= t < end`; прошедшие слова обычные, будущие бледнее).
- **В центре:** макеты интерфейса (экран приложения, чат, таблица, уведомление): их рисуешь HTML/CSS в компонентах Remotion, не скриншотами с чужими данными. Только вымышленные имена и цифры, пометь «демо» там, где это важно.
- **Камера летит по одному большому холсту** между сценами (общий трансформ translate/scale с пружиной), а не жёсткие склейки. Сцены лежат на холсте рядом, камера переезжает к следующей по таймкоду строки.
- **Счётчики цифр** (0 -> 1 250 000) с плавной остановкой на ключевых словах; не накладывай их друг на друга.
- **Финал:** призыв одним действием (кодовое слово или «ссылка в шапке»), на 2-3 секунды после последнего слова.
- Смена сцены минимум каждые 3-4 секунды; первые 3 секунды = хук, без логотипов и заставок.
- Тайминг сцен берёшь из `words.json` (`lines[i].start/end`), а не на глаз: единый файл `timeline` в проекте, от него считается всё.
Шаблон проекта Remotion в плагин не входит: собери минимальный проект сам (`npx create-video@latest`, TypeScript, пустой шаблон) и используй скилл `remotion-best-practices`, если он установлен.

## 4. Звук и громкость
- Дорожка озвучки основная. Музыка (если нужна, только с лицензией, разрешающей использование в Reels или из аудиотеки Instagram при публикации) на **-8...-12 дБ** ниже голоса, с приглушением (ducking) под речью по таймингам слов.
- Итоговая громкость около **-14 LUFS**, пик не выше -1 dBTP: после рендера доведи `loudness.py` из ffmpeg-skill (`ig-cut`, шаг 4).
- **Всегда отдавай две версии:** с музыкой и без музыки (`-nobgm`): пользователь может добавить трендовый звук в Instagram сам.

## 5. Рендер и превью
1. До финального рендера покажи превью: один ключевой кадр `npx remotion still <Composition> out/frame.png --frame <N>` или кусок 10 секунд `npx remotion render <Composition> out/preview.mp4 --frames=0-299`. Отправь пользователю, жди правок.
2. Финал: `npx remotion render <Composition> out/video.mp4` (1080x1920, 30 fps, h264). Не запускай рендер без «да» на превью.
3. Громкость и проверка:
   ```
   FF="$HOME/.claude/skills/ffmpeg-skill/scripts"
   python3 "$FF/loudness.py" out/video.mp4 -I -14 -o out/video_final.mp4 --overwrite
   python3 "$FF/check.py" out/video_final.mp4 --platform reels --content
   ```
   Исправь FAIL, повтори (подробнее в `ig-cut`).
4. Субтитры в этом формате уже в графике; отдельно жечь их не нужно.

## 6. Выдача
Покажи: файл (с музыкой и без), длительность, итог `check`, расход кредитов ElevenLabs. Подпись через `ig-caption` и `ig-human`. Публикация только через `ig-publish` и только после явного «да».
